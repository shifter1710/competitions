# Страница соревнования — Clean Admin P1

Интерфейс `/calendar/<id>` использует существующие Sanic-маршруты, SQLite,
серверные права и формы. Изменений схемы, API и формата результатов нет.
Перенесена композиция утверждённого A v2; остальные страницы не переделываются.

## Организация и поведение

Участники открываются первыми. Командные результаты, документы и сведения о
событии находятся во вкладках. Форма добавления участника открывается кнопкой;
при `add_participation` и возврате серверной ошибки она раскрывается автоматически.
Редкие формы документов и события — нативные раскрываемые блоки. Без JavaScript
разделы остаются в документе, формы доступны; вкладки работают как якорные ссылки.

Серверный фильтр сохраняет значения `result=with|without`: он проверяет место
`position`, а не текст `result`. Поэтому подписи теперь «С местом» и «Без места».
Глобальные счётчики участников, участий и отсутствующих мест не зависят от
поиска. Поиск по ФИО/группе применяется к загруженной серверной выборке, сохраняет
порядок и группы сервера; отдельная подпись показывает найденное количество.
Чип «Без места» переключает серверный фильтр, сохраняя поиск. Сброс снимает оба.

В редакторе доступны **все** прежние поля снимка участника и участия, а не только
место/результат. Enter сохраняет, Esc отменяет (при открытых подсказках ФИО эти
клавиши сначала управляют подсказками). Кнопки имеют текстовые подписи. Пока
идёт POST, повторное сохранение блокируется; ошибка оставляет ввод в форме.
Успешное сохранение перечитывает серверные данные, сохраняя фильтр, поиск,
вкладку и позицию. Если место изменилось и строка ушла из фильтра, это указано
в сообщении; фокус возвращается к фильтру. Защита beforeunload действует для
inline-правки и изменённой формы добавления. Пока есть несохранённый ввод,
вкладки и конкурирующие действия не переключаются; для новой записи есть
явная кнопка «Отменить добавление».

Поиск `q` и вкладка `tab` — URL-контекст. Session storage содержит одноразовый UI-контекст на 60 секунд: позицию/ID
фокуса, вкладку и введённую строку поиска (до 2000 символов), чтобы обычный
POST-редирект формы не терял выборку. Ключ ограничен ID события, запись удаляется
после чтения или сброса; явный `q` в адресе имеет приоритет. Данные строк,
черновики форм, файлы, пароли и сведения аккаунтов туда не записываются.
Поисковая строка может содержать введённое пользователем имя — она уже видна
в URL и временно сохраняется только как контекст поиска в этой вкладке браузера. Серверные параметры правки и
якоря `#documents`, `#protocols`, `#team-results` открывают соответствующую вкладку.

## Отличия от прототипа

- Реальный редактор сохраняет полную правку снимка, а не только два поля.
- Десять логических колонок сохранены для совместимости существующего JS;
  мобильный CSS показывает те же поля вертикально, без дублирования input/ID.
- Настройки обязательности/типа берутся из настоящей конфигурации полей.
- Кастомные поля, связывание карточек и разные права документов не упрощаются.
- Импорт открывает рабочий процесс, а не демонстрационный диалог.
- Не добавлены сортировка заголовками, экспорт или удаление события: этих
  действий не было в текущем контракте страницы.
- Реальные сохранения используют сервер и изолированную тестовую БД при QA.

## Проверка и границы

Автоматические тесты обновляют только изменённые UI-контракты (подписи фильтра,
маркер группы, компактное название импорта). Новые проверки покрывают порядок
разделов, role-specific forms, fallback без JS, prefill ошибки и глубокую ссылку
правки командного результата. Полный прогон и независимые browser/visual QA
отчитываются отдельно с фактическими числами; этот документ сам не заявляет PASS.

Новые зависимости, изменения backend/schema/auth и production-операции не
выполняются. Артефакты браузера, тестовые БД, synthetic Excel и логи находятся
вне Git. Следующий этап — приёмка владельцем; deploy/push/merge не входят в P1.


## TEAM-01: вкладка команд

Вкладка «Команды и результаты» содержит команды события и прежние командные результаты. Создание/переименование/дельты состава — admin/editor, чтение — viewer. Карточка команды показывает все участия события, дисциплины, предупреждение о несвязанной карточке и историю. Фильтр места основной страницы состав не ограничивает. [Полная матрица TEAM](team-01-02.md).

TEAM-02 дополняет прежнюю вкладку «Документы» режимом «Текущий состав команды».
Команда выбирается в обычной форме; поле доступно и без JavaScript. При ошибке
сохраняются текст и настройки, файл выбирается заново. В кабинете документ
показывается один раз с названием команды. Права вычисляются при запросе,
а не копируются на каждого получателя.
