## №1. Регистровые дубли в справочниках (уровни) — 2026-09-13

В справочнике уровней образовались пары «Внутривузовские/внутривузовские»,
«Межвузовские/межвузовские» (регистр). Источник — ручное добавление
значения в справочник с заглавной буквы (значения из импорта/записей
нормализуются в lower, ручное добавление — нет).

Владелец предложил 2 варианта: (1) объединять при переименовании —
отклонил сам (можно случайно испортить); (2) при добавлении/импорте
искать в справочнике без учёта регистра и подставлять каноническое
написание.

Аналитик: вариант 2 принят как направление. Уточнения при реализации:
охватить все пути записи значения (ручная запись, импорт, ручное
добавление в справочник — при добавлении с регистровым дублем отказать
с подсказкой); существующие регистровые дубли на проде чистятся
разово имеющимся инструментом (переименование с каскадом
«Внутривузовские» → «внутривузовские», записи обновятся).
