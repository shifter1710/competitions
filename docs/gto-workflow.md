# ГТО: персональный УИН, история и сертификаты

Откройте студента → вкладку «ГТО». УИН принадлежит карточке студента и общий
для всех его награждений. Admin выбирает «Изменить УИН»; это текст, например
полностью синтетический `0000123`, без преобразования в число. Можно оставить
пустым. Один и тот же непустой УИН у разных карточек запрещён; приложение
покажет понятную ошибку, карточки не объединяются. Editor/viewer УИН не меняют.

Для следующего награждения добавляйте отдельную запись ГТО. Например,
бронза, серебро и золото одного года/ступени — три строки с разными ID.
Повторные награды одного типа тоже допустимы. «Исправить запись» нужно для
ошибки в конкретном факте: audit хранит изменённые поля old/new. Год —
календарный год записи, ступень 1..18. Дату награждения вводите только если
она известна; без даты награда сохраняется. Статусы «Зарегистрирован» и
«Участвовал» сохраняют участие без награды; дата награждения к ним не относится.
Годы идут от новых к старым, внутри ступени известные даты — по хронологии,
неизвестные после известных; одинаковые записи различимы по ID.

К конкретной награде можно прикрепить несколько подтверждающих документов,
по одному за операцию: PDF, PNG или JPEG до 5 МиБ. Содержимое, расширение и
MIME должны соответствовать; пустой/generic MIME допускается при верных
расширении и сигнатуре. Имя очищается, внутреннее имя и пути пользователю
не выдаются. «Открыть»/«Скачать» всегда проверяют текущие права. Участие без
награды сертификат не получает. Неизвестный файл не блокирует награждение.

Admin/editor добавляют, исправляют и удаляют записи и документы. Viewer
только читает и скачивает. Athlete читает только собственные награждения и
сертификаты в существующем кабинете; доступ определяется актуальной стабильной
связью аккаунта, а не совпадением ФИО. Изменение группы/ФИО не удаляет историю.

Удаление документа требует явного подтверждения; удаление записи требует
подтверждения в её форме и удаляет связанные метаданные/файлы. Удаление
карточки с любой записью ГТО заблокировано. Чтобы исправить награду на участие,
сначала явно удалите сертификаты. После ошибки загрузки история и старые
сертификаты сохраняются, файл потребуется выбрать повторно. Файлы хранятся
в существующем дереве `data/files/gto/`, которое входит в общий backup вложений.
Отказ очистки после успешного удаления оставляет недоступный лишний файл для
операционного разбора и не отменяет уже выполненный commit.

Основные операции доступны с клавиатуры и без JavaScript, в обеих темах.

## Самостоятельный отчёт ГТО

Со страницы «Отчёты» откройте «Отчёт ГТО» (`/reports/gto`). Доступ —
admin/editor/viewer; athlete не получает массовый отчёт или XLSX. Фильтры:
календарный год записи ГТО, текущие институт/группа, ступень, тип награды,
поиск по текущему ФИО или текстовому УИН (без преобразования в число).
В каждом поле один критерий; пустое значение означает «Все», сочетания
полей работают через AND. Разные повторные значения одного параметра,
неизвестный тип награды и некорректные числовые/неподдерживаемые параметры
дают явную ошибку, без расширения выборки. Неизвестные институт/группа
сохраняются выбранными и возвращают честный ноль. Поиск учитывает регистр
кириллицы через casefold, совпадение имени не объединяет карточки.

Сначала нажмите «Применить». Таблица, показатели и «Скачать XLSX» относятся
к этим применённым условиям; изменённые, но ещё не отправленные поля экспорт
не меняют. Пустая выборка имеет нулевые показатели и XLSX с заголовками.
Каждая награда занимает одну строку, независимо от числа сертификатов.
«Уникальных студентов» считает стабильные Student ID, «Награждений» —
стабильные ID наград; бронза/серебро/золото суммируются в число награждений.
registered/participated, неизвестные legacy-статусы и нарушенные связи с
несуществующей карточкой в награды отчёта не входят. Неактивные карточки
сохраняют свои исторические награды в отчёте.

Институт/группа — ТЕКУЩИЕ сведения карточки, не исторический снимок.
После смены группы классификация отчёта меняется, сами ID/даты/награды
сохраняются. Строки упорядочены по году DESC, ступени ASC, известной дате ASC
(неизвестные после известных), имени/Student ID/ID награды для разрешения равенств.
Ссылка студента открывает его ГТО и позволяет вернуться к применённому отчёту,
включая после обычного сохранения или ошибки формы без JavaScript.

В XLSX есть ID награждения/студента, ФИО, УИН, текущие институт/группа,
год/ступень/награда/известная дата и сведения о сертификатах с защищёнными
относительными ссылками. Внутренние файловые пути не экспортируются. УИН
сохраняется буквальной строкой с текстовым форматом, включая ведущие нули
и значения, начинающиеся с `=`. Остальной пользовательский текст защищён
от формул существующим sanitizer. Если текст нельзя без потерь представить
в ячейке XLSX, экспорт сообщает ошибку; исходные значения не обрезаются и
приложение не вводит произвольного ограничения длины УИН.

Нативные GET-формы, клавиатура, мобильная ширина и обе темы поддерживаются.
Reports v2 и REP-05 не меняют своих условий или подсчётов.
