# Роли: что я могу делать в системе

В системе четыре роли: `admin`, `editor`, `viewer`, `athlete`. Роль видна
в шапке рядом с логином. Ниже — по разделу на роль: что доступно и где в
интерфейсе, что недоступно. Общие для всех правила (сессии, CSRF,
историчность) — в конце.

Сводка:

| | admin | editor | viewer | athlete |
|---|---|---|---|---|
| Реестр записей | да | да | да | только свои и «по своим ФИО» |
| Ввод и правка записей | да | да | нет | да (на проверке) |
| Импорт / шаблон | да | да | нет | нет |
| Модерация записей | да | да | нет | нет |
| Отчёт «количество участий» и выгрузки | да | да | да | нет |
| Вложения | да | да | колонка скрыта* | к своим записям |
| Документы соревнования | да | да | просмотр и скачивание | только доступные его карточке студента |
| Протоколы соревнования | да | да | просмотр и скачивание | протоколы всех своих соревнований |
| Список и карточки студентов (просмотр) | да | да | да | нет |
| Доступ атлета на карточке студента: выдача, смена пароля, включение/отключение | да | да | нет | нет |
| Записи ГТО (добавление/правка/удаление) | да | да | нет | только свои в кабинете (чтение) |
| Пользователи, справочники, студенты (правка карточек/merge/импорт), обслуживание БД, аудит | да | нет | нет | нет |
| Профиль атлета | нет** | нет** | нет** | да |

\* Колонка «Вложения» отображается только ролям с правом записи; у viewer
кнопок прикрепления нет.

\** Страница «Профиль» существует только для роли athlete, остальные роли
получают заглушку «Профиль доступен только пользователям с ролью athlete».

## admin — администратор

Может всё, включая деструктивные действия.

**Записи**

- Вводить записи вручную (кнопка «+ Пустая строка» в реестре) — статус сразу
  «подтверждена».
- Редактировать любую запись (в ячейках таблицы или кнопкой
  «Редактировать»); правка администратора автоматически подтверждает запись.
- Удалять любые записи (кнопка «Удалить» в колонке «Действия») — только
  эта роль.
- Прикреплять и скачивать вложения к любым записям, удалять любые вложения
  (кнопка × у файла).
- Управлять документами соревнования на странице события (секция «Документы
  соревнования»: загрузка, правка названия/файла/доступа, удаление) и
  скачивать их.
- Управлять протоколами соревнования на странице события (секция «Протоколы
  соревнования»: загрузка, правка названия/файла, удаление) — доступ
  протоколов не настраивается, они всегда видны всем участникам; скачивать
  их.
- Связывать запись без соревнования с событием календаря (иконка-звено в
  строке реестра): выбрать существующее с предпросмотром изменений или
  создать новое соревнование прямо со страницы записи.

**Модерация**

- Подтверждать («✓ Подтвердить») и отклонять («✗ Отклонить», с комментарием)
  записи атлетов прямо в реестре.

**Импорт и шаблоны**

- Импорт xlsx-файлов (кнопка «Импорт» над реестром или «Админ → Импорт
  реестра»); скачивать пустой шаблон с учётом кастомных полей. Похожие на
  существующие строки попадают в очередь подтверждения — её разбирает админ.

**Админка** (хаб «Админ» в меню, admin-only; эдитору — плитка «Импорт
реестра», сам импорт также открывается кнопкой «Импорт» над реестром)

- **Пользователи** (admin): создавать учётки с любой ролью (логин не может
  содержать двоеточие и управляющие символы), менять пароли
  (сессии целиком сбрасываются), включать/отключать учётки (свою отключить
  нельзя), привязывать дополнительные ФИО-псевдонимы к аккаунту.
- **Кастомные поля** (admin): создавать дополнительные поля записей
  (текст/число/дата/ссылка), настраивать обязательность, видимость в
  таблице/выгрузке/шаблоне, отключать поля.
- **Справочники** (admin): значения видов спорта и институтов, уровни
  соревнований — добавить, скрыть из подсказок, удалить (если на значении
  нет записей). Учебные данные группы (кнопка «Обучение…»: уровень
  образования, год поступления, длительность обучения — год из названия
  группы предлагается только предзаполнением) и справочник «Уровни
  образования» (длительность по умолчанию, скрыть/показать, удалить уровень
  без групп).
- **Объединение студентов (merge)** (admin): перенести записи со старого
  ФИО на новое — с предпросмотром счётчика, опцией перезаписи отображаемых
  ФИО и автоматическим переносом псевдонимов. Открывается из раздела
  «Студенты» (кнопка «Объединение студентов»).
- **Студенты и импорт студентов из Excel** (admin): правка карточек,
  псевдонимы, деактивация, удаление ошибочных карточек и сопоставление
  данных — только админ; раздел «Студенты» в верхнем меню (список и
  карточки для чтения открыты всему штату — см. ниже). Импорт списка
  студентов («Студенты → Импорт из Excel») с предпросмотром: ничего не
  сохраняется, пока строки не подтверждены (редактору раздел недоступен,
  его импорт — только записи соревнований).
- **Записи ГТО** (admin + editor): на карточке студента — таблица «ГТО»
  (год, ступень, результат) с добавлением, правкой и удалением записей.
- **Доступ атлета** (admin + editor): на карточке студента — секция
  «Доступ атлета»: выдача аккаунта атлета, привязанного к этой карточке
  (логин подсказывается из ФИО, пароль показывается один раз до создания),
  смена пароля и включение/отключение доступа (см. editor ниже).
- **Обслуживание базы** (admin): выгрузить всю базу в один xlsx (листы:
  записи, пользователи, уровни, виды спорта); массовое связывание записей
  без соревнования с календарём — предпросмотр совпадений по названию и
  датам и кнопка «Связать» (неоднозначные записи связываются только
  вручную, со страницы записи); заполнение годов поступления у старых
  записей («Годы поступления (записи)») — предпросмотр распознавания года
  по историческому названию группы и заполнение только однозначных
  случаев; очистка в два шага —
  «все записи», «записи + вложения» или «только вложения» плюс ввод слова
  «УДАЛИТЬ». Пользователи, кастомные поля, справочники и журнал аудита
  очистка не трогает.
- **Журнал безопасности** (admin, `/admin/audit`): аудит-лог входов, смен
  паролей, модерации, merge, привязок псевдонимов и очисток — только
  чтение, последние события сверху.

## editor — оператор (модератор)

Предназначен для ввода данных и работы с записями.

**Может**

- Вводить записи вручную (статус сразу «подтверждена»), редактировать любые
  записи — правка эдитора, как и админа, автоматически подтверждает запись.
- Прикреплять вложения (PDF/JPEG/PNG до 5 МБ) к любым записям и скачивать их.
- Импортировать xlsx и скачивать пустой шаблон (кнопка «Импорт» над
  реестром; она же ведёт в раздел «Импорт реестра»). Похожие на существующие
  строки уходят на подтверждение администратору.
- Работать с календарём соревнований: создавать/редактировать события,
  прикреплять файл положения, добавлять участников (подсказки ФИО включают
  карточки студентов — явный выбор карточки заполняет пустые поля и
  записывает связь), вести командные результаты события (категория +
  место команды на странице соревнования), управлять документами
  соревнования — загрузка PDF/JPEG/PNG до 5 МБ, правка названия/файла/
  доступа, удаление; доступ к документу задаётся «всем участникам» или
  выбранным карточкам студентов — и скачивать их. Управлять протоколами
  соревнования (секция «Протоколы соревнования»: загрузка, правка
  названия/файла, удаление) — протоколы всегда видны всем участникам,
  доступ не настраивается.
- Связывать записи без соревнования с событиями календаря (иконка-звено в
  строке реестра) — выбрать существующее или создать новое соревнование со
  страницы записи.
- Импортировать участников события из Excel (кнопка «Импортировать
  участников из Excel» на странице события): предпросмотр, выбор
  существующих карточек, правка/пропуск строк, массовое добавление.
- Модерировать записи атлетов: подтверждать / отклонять с комментарием.
- Видеть полный список ФИО из записей (он и так виден эдитору в общей
  таблице; API полного списка отдаётся только admin/editor).
- Открывать раздел «Студенты» и карточки студентов (данные — read-only):
  смотреть актуальные данные, псевдонимы, связанные записи/аккаунты.
- Вести записи ГТО на карточке студента: добавлять, править и удалять
  записи «год + ступень + результат» (те же действия, что у админа).
- Выдавать, отключать и включать доступ атлета, менять пароль его
  аккаунта на карточке студента (секция «Доступ атлета»: логин
  подсказывается из ФИО — «Иванов Иван Иванович» → ivanov_ii, при
  коллизии предлагается свободный вариант; пароль генерируется на
  клиенте и показывается один раз до создания, в базе — только хеш).
- Пользоваться отчётом, выгрузкой таблицы и отчёта в Excel, тёмной темой.

**Не может** (в меню и на страницах этого нет, API вернёт 403)

- Управлять пользователями и паролями в разделе «Админ → Пользователи»
  (выдача/управление доступом атлета на карточке студента — можно,
  см. выше).
- Управлять справочниками и кастомными полями.
- Делать merge студентов.
- Создавать/править/удалять карточки студентов и их псевдонимы, деактивировать
  карточки, сопоставлять записи/аккаунты — в том числе действием «Создать
  нового Student и добавить участника» в импорте участников события
  (доступен только выбор существующей карточки и пропуск; создание
  карточек — раздел «Студенты», admin-only).
- Выгружать/очищать базу (обслуживание).
- Смотреть журнал аудита.
- Удалять записи и вложения (это admin-only).

## viewer — наблюдатель

Только чтение.

**Может**

- Смотреть реестр записей с сортировкой, скрытием/перетаскиванием колонок.
- Формировать отчёт «количество участий» с фильтрами (ФИО, даты, место,
  уровень, кастомные поля).
- Выгружать в Excel текущий вид таблицы и отчёт (с выбором колонок).
- Смотреть список документов соревнования на странице события и
  скачивать их (без кнопок управления).
- Смотреть протоколы соревнования на странице события (секция «Протоколы
  соревнования») и скачивать их (без кнопок управления).
- Открывать раздел «Студенты» и карточки студентов в режиме чтения:
  список с поиском и сортировкой, на карточке — данные студента,
  псевдонимы, связанные записи/аккаунты, секцию «Доступ атлета»
  (логин и статус) и таблицу «ГТО» (без форм).

**Не может**

- Добавлять, редактировать, удалять записи и вложения (нет кнопок ввода).
- Импортировать, модерировать, видеть админку.
- Менять что-либо в разделе «Студенты», включая записи ГТО и выдачу
  доступа атлета (нет кнопок).

## athlete — атлет

Личный кабинет: «Мои соревнования» на главной + страница «Профиль».

**Видит**

- Свои записи (созданные этим аккаунтом) плюс записи, привязанные по любому
  из его ФИО — из профиля и псевдонимов (привязка через хеш ФИО). Так
  участия, внесённые оператором заранее, «подтягиваются» в кабинет
  автоматически, без кнопки «забрать записи».
- Статус каждой своей записи виден как бейдж: «на проверке», «отклонена»
  (комментарий модератора — в подсказке бейджа) или «подтверждена».
- Карточку «Мои документы» на главной: документы соревнований,
  доступные его карточке студента («всем участникам» — если карточка
  участвует в событии, «выбранным студентам» — если карточка выбрана
  явно), сгруппированные по событию; скачивание — прямо из кабинета.
  Документы, к которым карточка прав не имеет, не видны и по прямой
  ссылке не скачиваются (403). Протоколы соревнования (бейдж «Протокол»)
  видны всегда — карточка участвует в событии.
- Карточку «ГТО» на главной (только при привязке к карточке студента и
  наличии записей): свои ступени и результаты комплекса по годам,
  только чтение — записи ведут модераторы на карточке студента.

**Может**

- Добавлять свои участия кнопкой «+ Пустая строка» в реестре — основные
  поля (ФИО, пол, институт, группа, курс) автоподставляются из профиля,
  введённое вручную всегда приоритетнее. Всё новое уходит «на проверке».
- Редактировать свои записи и записи «по своим ФИО» — правка снова
  отправляет запись «на проверке» (независимо от прежнего статуса).
- Прикреплять и скачивать вложения к своим записям.
- Заполнить «Профиль» (ФИО, пол, институт, группа, курс). ФИО из профиля
  дописывается в псевдонимы аккаунта (список только растёт) — смена
  фамилии ничего не отрывает. Под полем ФИО — подсказка: найдены ли записи
  с таким ФИО (без раскрытия чужих данных, только «найдено/не найдено»).

**Не может**

- Видеть общий реестр и чужие записи, отчёты и выгрузки (раздел «Отчёты»
  скрыт, выгрузка отключена).
- Видеть список чужих ФИО в каком-либо виде.
- Импорт, модерация, админка.

## Общие правила

- **CSRF**: все POST-запросы идут с токеном из `<meta name="csrf-token">`;
  фронтенд прикрепляет его сам, от пользователя ничего не требуется. Запрос
  без токена отклоняется (403).
- **Сессия**: вход — подписанная cookie на 12 часов. Смена пароля
  администратором (или вам) отзывает активные сессии этого аккаунта —
  придётся войти заново. После 5 неудачных попыток входа с одного IP вход
  блокируется на 3 минуты.
- **Историчность записей**: запись о соревновании — факт на дату. Группа,
  институт, курс и ФИО в существующих записях не перезаписываются при
  смене профиля: в 2024 студент выступал за группу ПГС-101 — так это и
  останется в записях и отчётах за 2024. Текущие значения из профиля
  подставляются только в новые записи.
- **Приватность ФИО**: полный список ФИО студентов доступен только
  admin/editor. Атлету система сообщает лишь факт «есть ли записи с таким
  ФИО» о конкретном введённом имени.
