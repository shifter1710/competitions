Как заполнить файл

  • Обязательное поле — только ФИО; пол, институт, группу, курс и место можно оставить пустыми.
  • Название, даты, уровень и вид спорта брать из файла не нужно — они уже известны из соревнования.
  • Если ФИО совпадает с карточкой студента, пустые поля подтянутся из неё; явные значения файла имеют приоритет, карточка студента при этом не меняется.
  • Место можно оставить пустым — участник будет «ждать результата», место допишете позже.
  • Необязательные колонки «Дисциплина» и «Результат»: дисциплина различает участия одного человека (100 м и 200 м — два участия), результат сохраняется в записи участия. Повтор уже существующего участия не создаётся — предпросмотр пометит строку «уже существует», а при других месте/результате предложит обновить существующее.
  • Лишние колонки в файле игнорируются.
  • Ничего не добавляется, пока вы не подтвердите строки на странице предпросмотра.
